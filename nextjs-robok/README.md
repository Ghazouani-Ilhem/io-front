# Robok - AI Agency & Technology (Next.js Version)

This is a Next.js conversion of the original Robok HTML template. The website has been successfully converted from static HTML to a modern Next.js application with TypeScript support.

## Features

- ✅ **Next.js 15** with App Router
- ✅ **TypeScript** for type safety
- ✅ **Tailwind CSS** for utility-first styling
- ✅ **Responsive Design** with Bootstrap integration
- ✅ **Component-based Architecture** with reusable React components
- ✅ **Modern JavaScript** with ES6+ features
- ✅ **SEO Optimized** with proper meta tags
- ✅ **Performance Optimized** with Next.js optimizations

## Components

The original HTML has been broken down into reusable React components:

- **Header**: Navigation with responsive menu and side menu
- **Footer**: Footer with company information and links
- **Banner**: Hero section with brand carousel
- **About**: About section with company information
- **Services**: Services showcase with interactive elements
- **Process**: How it works section
- **Projects**: Portfolio showcase
- **Team**: Team members display
- **Testimonials**: Customer testimonials carousel
- **FAQ**: Frequently asked questions accordion
- **Blog**: Latest blog posts
- **Preloader**: Loading animation

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Start production server:**
   ```bash
   npm start
   ```

## Customization

The components are modular and easy to customize:

1. **Styling**: Modify the CSS files in `public/assets/css/`
2. **Content**: Update the data in each component
3. **Layout**: Modify the layout in `src/app/layout.tsx`
4. **Pages**: Add new pages in the `src/app/` directory
